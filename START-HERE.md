## 🚀 How to Get Started (5 minutes)

### 1. Run the Application
```bash
# Open terminal/command prompt
cd "YAS-Order-Tracking-Frontend"

# Start web server
python -m http.server 8000

```

### 2. Explore the App
- **Sales Dashboard**: View orders with search/filter
- **New Order Form**: Create test orders (auto-generates ID)
- **Driver Interface**: Update order status and location
- **Customer Tracking**: Track orders securely
- **Admin Stub**: Foundation for Phase 2

### 3. Test the Features
- Create a new order
- Search for orders
- Update order status
- Try tracking an order
- Check responsive design (F12 → Device toolbar)
