## 🎓 HOW TO USE

### Quick Start
```bash
# 1. Navigate to project directory
cd YAS-Order-Tracking-Frontend

# 2. Start web server
python -m http.server 8000

# 3. Open in browser
http://localhost:8000

# 4. Explore the app
- Navigate between views using sidebar
- Create test orders
- Update order status
- Track orders
```

### Running Tests
```bash
# In browser console (F12):

// Load test suite
const script = document.createElement('script');
script.src = 'test-suite.js';
document.head.appendChild(script);

// View results
console.log(window.TEST_REPORT);

// Export as JSON
JSON.stringify(window.TEST_REPORT, null, 2);
```

### Testing Features
1. **Create Order**: Fill form → Submit → See in dashboard
2. **Search/Filter**: Type in search box or select status
3. **Update Status**: Driver view → Select new status → Update
4. **Track Order**: Public tracking → Enter ID + Phone → View progress
5. **Location**: Driver → Click location button → Allow → See update
