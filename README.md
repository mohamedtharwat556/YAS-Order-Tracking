# YAS Order & Delivery Management System

نظام إدارة الطلبات والتوصيل

## البدء السريع

### محليًا:
```bash
# فتح index.html في المتصفح
open index.html
```

### على Vercel:
```bash
vercel
```

## الملفات

- `index.html` - لوحة المبيعات
- `driver.html` - واجهة السائق
- `track.html` - صفحة تتبع العميل
- `assets/css/style.css` - التنسيقات
- `assets/js/` - ملفات JavaScript

## الميزات

✅ لوحة بيعات كاملة
✅ واجهة سائق
✅ صفحة تتبع عميل
✅ دعم عربي RTL
✅ متجاوب مع الهاتف
