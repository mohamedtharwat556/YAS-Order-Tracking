# YAS Order & Delivery — Frontend Demo

## تشغيل المشروع
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث. الأفضل تشغيله عبر VS Code Live Server.
3. استخدم القائمة الجانبية للتنقل بين لوحة الطلبات، تسجيل طلب، واجهة السائق، وتتبع العميل.

## الموجود حاليًا
- لوحة مبيعات وإحصائيات وبحث/فلترة.
- نموذج تسجيل طلب جديد وتوليد رقم طلب تلقائي.
- واجهة سائق لتحديث حالة الطلب يدويًا ومشاركة الموقع بزر.
- صفحة تتبع تطلب رقم الطلب ورقم الهاتف.
- حفظ بيانات تجريبية على نفس المتصفح باستخدام localStorage.

## مهم قبل الإنتاج
هذه نسخة Frontend فقط. البيانات لا تتزامن بين أجهزة مختلفة، وlocalStorage ليس قاعدة بيانات آمنة. قبل النشر العام يجب بناء Backend وقاعدة بيانات ومصادقة وصلاحيات فعلية، والتحقق من أرقام الهواتف/الطلبات على الخادم. الموقع اليدوي يتطلب إذن المتصفح وغالبًا HTTPS أو localhost.
